Política de Privacidade

Esta política descreve o Claude Continuity, aplicativo pessoal mantido por HuanBellini, e estas páginas públicas de documentação.

Dados tratados pelo aplicativo

O aplicativo pode processar arquivos locais expressamente autorizados pelo proprietário, como históricos de sessões, configurações e instruções. Esses arquivos podem conter informações pessoais ou confidenciais e devem ser selecionados com cuidado. A captura de históricos reais e seu envio dependem de autorização específica.

A conexão OAuth armazena credenciais e tokens localmente para permitir acesso autorizado ao Google Drive, inclusive renovação de acesso quando permitida pelo Google. Esses dados não são publicados neste site, no repositório público ou nos backups destinados ao Drive.

Finalidade e permissão do Google

O acesso ao Google Drive é usado exclusivamente para as operações de armazenamento e recuperação autorizadas pelo proprietário. O escopo solicitado é https://www.googleapis.com/auth/drive.file, limitado aos arquivos criados pelo aplicativo ou disponibilizados especificamente a ele. O aplicativo não solicita acesso geral ao conteúdo do Drive.

Armazenamento e compartilhamento

O processamento principal ocorre no computador do proprietário. Quando expressamente autorizado, cópias criptografadas de backup podem ser transferidas diretamente para sua conta Google Drive pelo Rclone. A senha de recuperação deve ser mantida separadamente e não deve acompanhar a cópia na nuvem.

O projeto não opera um servidor próprio para receber históricos ou credenciais. Não vende dados, não utiliza dados para publicidade e não os envia para treinamento de modelos de inteligência artificial. O Google processa os arquivos enviados e os dados de autorização segundo suas próprias políticas.

O uso de criptografia não elimina todos os metadados: os provedores podem processar informações operacionais como nome de objetos criptografados, tamanho, horários de transferência e dados de conexão. O conteúdo só é protegido quando o arquivo enviado é de fato um backup criptografado.

Retenção, exclusão e revogação

Backups locais e cópias no Drive permanecem até que o proprietário execute uma política de retenção ou exclusão. Excluir um histórico original não remove automaticamente todas as versões de backup. A configuração atual não promete exclusão automática.

O proprietário pode revogar o acesso em Conexões da Conta Google. A revogação impede novas operações autorizadas pelo token revogado, mas não apaga automaticamente arquivos já armazenados. A exclusão desses arquivos e das credenciais locais é uma operação separada, sob controle do proprietário.

Privacidade deste site

Estas páginas são estáticas, hospedadas pelo GitHub Pages, sem formulários, scripts de análise, cookies adicionados pelo projeto ou recursos externos incorporados. O GitHub pode registrar dados técnicos de acesso conforme sua Política de Privacidade. Links externos são operados pelos respectivos provedores.
